# Hosted Llama evaluation

Produce resumable zero-shot and ten-shot predictions from the configured endpoint.

Run commands from the repository root.

| Entry point | Purpose |
|---|---|
| [run_hosted_llama_evaluation.py](run_hosted_llama_evaluation.py) | Run requests or collect saved responses for a hosted Llama condition. |

Private responses and predictions stay in `methods_runs/hosted_llama_*/`. Provider access is required; the recorded mutable alias does not guarantee identical future weights.
