# Natural diagnosis contrasts

Compare predictions on difficult diagnosis pairs from existing cases.

Run commands from the repository root.

| Entry point | Purpose |
|---|---|
| [analyze_difficult_contrasts.py](analyze_difficult_contrasts.py) | Produce subset metrics and a private case-review worksheet; this is not a synthetic minimal-pair experiment. |

Generated aggregates and private worksheets go to `methods_runs/difficult_contrasts/`; published aggregates remain in the linked result directory.
